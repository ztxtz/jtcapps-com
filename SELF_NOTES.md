# Project memory

- Hosting repository: https://github.com/ztxtz/jtcapps-com. Cloudflare Pages project `jtcapps-site` serves the site, published by `./deploy.sh` (source `~/.config/ios-secrets/app-api-cloud.env` for `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`); pushing to `main` does not deploy. DNS is on Cloudflare. A machine with a stale resolver can still see the old GitHub Pages address and a "Site not found" 404, so verify with `dig @1.1.1.1` before treating that as an outage.
- Homepage rule from the owner: abstract, with copy about craft rather than apps. The only app material on `/` is the link cards at the bottom-left of the hero, each opening an app's site in a new tab with a homepage thumbnail. No app icons. Refresh a thumbnail when that site's look changes. Contact is info@jtcapps.com, a real mailbox.
- `README.md` has the file layout and verification list. The Unfeast repo's bundle still contains the previous homepage, so importing all of it would overwrite this one. Habumi's bundle in `tom28881/orbit-habit-tracker` uses the legacy `habisat/` folder and `/habisat/` internal links; deploy it at `habumi/` with internal `/habisat/` links rewritten to `/habumi/`. Hold the Scroll's bundle in `tom28881/space` (`web/landing/dist/`) deploys at `hold-the-scroll/` without the sibling `privacy.html`/`support.html`/`terms.html` stubs (handled via `_redirects` so Cloudflare Pages Pretty URLs does not clash with `*/index.html`).
